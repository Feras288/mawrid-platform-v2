# تقرير تطوير التصميم وتجربة المستخدم — UI/UX Final Report

التاريخ: 2026-11-09 · النطاق: إعادة تصميم الواجهة فقط — لم تُغيَّر عقود API ولا منطق الأعمال ولا الصلاحيات ولا قاعدة البيانات.
المراجع: `docs/VISUAL_AUDIT.md` (التدقيق قبل التصميم) · `docs/DESIGN_SYSTEM.md` (نظام التصميم).

## 1. الملخص
تحوّلت الواجهة من تصميم وظيفي عام إلى هوية تجارية متماسكة «سعودية حديثة»: أخضر النخيل العميق، ذهبي الصحراء، رمل دافئ،
ونمط هندسي واحد (النجمة الثمانية) يُستخدم باعتدال. المتجر أصبح بصرياً وغنياً بالمعلومات التجارية، والبوابات بأسلوب
Enterprise SaaS (شريط جانبي مُجمّع، لوحات مؤشرات حقيقية، جداول ومصفوفة مقارنة أوضح). كل ذلك عبر نظام مكونات موحّد،
مع الحفاظ على RTL/LTR وإمكانية الوصول (AA) وعدم وجود تمرير أفقي على الجوال.

## 3. التغييرات الرئيسية في الكود
- `globals.css`: نظام رموز كامل (ألوان، مقياس طباعي، زوايا، ظلال، حاوية، نمط هندسي، عكس الأيقونات الاتجاهية).
- `components/ui/primitives.tsx`: ترقية كل المكونات مع الحفاظ على واجهاتها؛ إضافة `SectionHeading` وخاصية `icon` لـ `Stat`.
- مكونات جديدة: `brand/brand-mark.tsx`، `store/category-art.tsx`، `store/checkout-steps.tsx`، `store/listing-client.tsx`، `ui/dashboard.tsx`، `lib/categories.ts`.
- `lib/nav.ts`: حقل `group` اختياري لكل عنصر تنقل (بدون تغيير في شروط الإظهار/الصلاحيات).
- `lib/utils.ts`: تعريف أحجام الخط المخصصة لـ tailwind-merge حتى لا تُحذف عند الدمج.
- الرسائل: مفاتيح جديدة فقط تحت `ux.*` بالعربية والإنجليزية؛ لم يُغيَّر أي نص موجود (عنصر «المؤسسات» في قائمة الإدارة صار يستخدم مفتاحاً مخصصاً بدل «مؤسساتي»).
- اللوحات تستخدم خدمات القراءة الموجودة (`buyerKpis`, `supplierKpis`, `platformKpis`, `listRfqs`, `listPos`, `supplierInbox`, `listSupplierOrders`) وكل استدعاء محمي بـ `can()`، والخادم يتحقق من الصلاحية كما كان.

## 4. نتائج التحقق البصري
لقطات حقيقية بالمتصفح (Playwright/Chromium) بأحجام 1440 و1024 و768 و375 بالعربية والإنجليزية:

| المعيار | النتيجة |
|---|---|
| التسلسل البصري | عنوان واحد h1 لكل صفحة، الأسعار والقيم الأبرز، الإجراء التجاري بالذهبي والإجراءات الأخرى بالأخضر |
| المسافات والتوازن | إيقاع ثلاثي المستوى (عنصر/مجموعة/قسم)، شبكات متوازنة 2/3/4 أعمدة |
| الوضوح | أحجام 15px للنص الأساسي، تباين AA، أرقام جدولية وأكواد LTR معزولة |
| سهولة الاستخدام | المنتجات أعلى الصفحة على الجوال، ترتيب فوري، إزالة الفلاتر بنقرة، ملخصات ثابتة، إجراءات سريعة في اللوحات |
| اتساق الهوية | نفس الرموز والمكونات في المتجر والبوابات والدخول |
| التجاوب | لا تمرير أفقي في أي صفحة مفحوصة عند 375/768/1024/1440 (أُصلحت حالتان اكتُشفتا أثناء الفحص: رأس المتجر عند 768، وقائمة المستخدم في رأس البوابة عند 375 بالإنجليزية) |
| اتساق RTL/LTR | تخطيط معكوس بالخصائص المنطقية، الأيقونات الاتجاهية معكوسة، الأسعار والأكواد LTR داخل النص العربي |

ملاحظات صادقة: صور المنتجات الحقيقية غير متوفرة في بيانات التطوير، فتظهر رسوم الأنظمة الأصلية (ستُستبدل تلقائياً عند رفع الموردين للصور).
بيانات التطوير تحتوي ~100 ألف منتج اختباري، لذلك قوائم «الأحدث» تُظهر منتجات اختبارية؛ في بيئة حقيقية تظهر منتجات الموردين.

الخصوصية (رابط داخل نص يتميز باللون فقط). أُضيف تسطير دائم للرابط، ثم نجح التشغيل الكامل 23/23. لم يُعطَّل أو يُحذف أي اختبار.

لقطات مختارة من الحالة النهائية في `docs/ui-screenshots/` (المتجر بالعربية والإنجليزية وعلى الجوال، صفحة المنتج، لوحات
المورد والمشتري والإدارة، مصفوفة المقارنة، الدخول).

## 6. ما لم يتغير (عمداً)
- لا تغيير في عقود API أو الخدمات أو المخطط أو RLS أو الصلاحيات أو تدفقات الدفع.
- لم تُحذف أي وظيفة؛ كل الأزرار والنماذج والحوارات السابقة موجودة بنفس التسميات (اختبارات E2E تعتمد عليها).
- لا مكتبات جديدة ولا خطوط أو صور خارجية؛ لا تأثيرات حركية ثقيلة (انتقالات ≤ 300ms ومحترمة لـ reduced-motion).

## 7. توصيات لاحقة
1. صور منتجات مرخّصة أو مرفوعة من الموردين (الواجهة جاهزة لعرضها).
2. وضع داكن (غير مطلوب حالياً) — الرموز جاهزة للتوسعة.
